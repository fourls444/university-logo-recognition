# University Logo Recognition

แอปในเครื่องสำหรับจัดอันดับมหาวิทยาลัยจากภาพโลโก้ พร้อมบันทึกคำตอบที่แก้ไขเพื่อตรวจทานก่อนใช้ฝึกครั้งถัดไป

## เริ่มใช้งาน

```powershell
python -m pip install -r requirements.txt
python train.py --epochs 10
python -m streamlit run app.py --server.address 127.0.0.1
```

เปิดที่อยู่ที่ Streamlit แสดง จากนั้นอัปโหลดภาพสีหรือขาวดำขนาดไม่เกิน 20 MB แล้วกด **ค้นหาโลโก้** ได้ทันที ระบบใช้ทั้งภาพเป็นค่าเริ่มต้น พื้นหลัง ข้อความ หรือหลายโลโก้ในภาพอาจทำให้ความแม่นยำลดลง

หากต้องการครอบภาพ กด **Crop image** แล้วลากจุดจับหรือขอบได้ทันที กด **Apply crop** เพื่อใช้ภาพ หรือ **Cancel** เพื่อยกเลิก กลับไปใช้ต้นฉบับได้ด้วย **Use full image** ภาพพรีวิวอยู่ในกรอบขนาดคงที่โดยรักษาสัดส่วนเดิม

การฝึกครั้งแรกต้องใช้อินเทอร์เน็ตเพื่อดาวน์โหลดโมเดลภาพพื้นฐาน หลังจากนั้นการทำนายใช้ไฟล์ในเครื่อง

แอปแสดงสูงสุด 5 อันดับพร้อม **คะแนนโมเดล** และเว็บไซต์มหาวิทยาลัย คะแนนใช้จัดอันดับ ไม่ใช่เปอร์เซ็นต์ความคล้ายหรือการรับประกันความถูกต้อง ระบบแจ้งเมื่อไม่มั่นใจและรองรับคำตอบไม่รู้จัก

แก้ไขคำตอบแล้วบันทึก แอดมินสามารถอนุมัติ ปฏิเสธ และส่งออกได้จาก **Review** ข้อมูลเก็บใน `feedback/` ไม่มีการฝึกซ้ำอัตโนมัติ

ตั้งรหัสแอดมินเฉพาะอย่างน้อย 16 ตัวอักษรใน `.streamlit/secrets.toml` ชื่อ `review_admin_password` ตามรูปแบบ `.streamlit/secrets.example.toml` หรือใช้ตัวแปร `REVIEW_ADMIN_PASSWORD` บนเซิร์ฟเวอร์ ไฟล์รหัสจริงถูก Git ignore

เมื่อตรวจคำตอบแล้ว ใช้ `python train.py --epochs 10 --include-feedback` เพื่อฝึกโมเดลรุ่นใหม่จากข้อมูลที่อนุมัติแล้ว

ทดลองฝึกโดยไม่เปลี่ยนโมเดลที่ใช้งาน ใช้ `python train.py --epochs 10 --no-promote`

แท็บ **Training** แสดงจำนวนภาพ กราฟ และผลตรวจของโมเดลปัจจุบัน

## ข้อมูลและโมเดล

`dataset.py` เตรียมข้อมูลและปรับภาพร่วมกันระหว่างการฝึกและการทำนาย การฝึกเขียน `model.keras`, `labels.json` และ `metadata.json` ภายใต้ `artifacts/versions/<version>/` และเลือกชุดปัจจุบันผ่าน `artifacts/current.json` แอปใช้ชุดนี้ร่วมกัน โดยไม่ใช้ไฟล์โมเดลเก่าทดแทน

ตรวจสอบระบบ:

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```


ภาพโลโก้อยู่ใน `data/logos/` ภาพตัวอย่างใน `data/examples/` และข้อมูลที่เตรียมเพิ่มใน `data/candidates/` โดย `dataset_manifest.json` ระบุชุดข้อมูลที่ใช้งาน ดูรายละเอียดที่ [dataset organization](docs/dataset-organization.md)

สร้างภาพดัดแปลงแยกไว้ด้วย `python scripts/augment_dataset.py`
